# 4. REGLA DEL SPLIT

Existe un porcentaje de distribución modelo/estudio.

Valor por defecto:

```text
60% → Modelo
40% → Estudio
```

Este porcentaje se denomina:

```text
split
```

REGLA ABSOLUTA:

Solo el **Súper Administrador** puede modificar el split.

El Administrador NO puede modificarlo.

El Monitor NO puede modificarlo.

El Modelo NO puede modificarlo.

No permitas que una modificación del frontend pueda eludir esta regla.

La protección debe existir en backend.

---

# 5. REGLA DE ELIMINACIÓN DE MODELOS

El Administrador y el Monitor:

* pueden crear modelos cuando corresponda;
* pueden editar modelos;
* NO pueden eliminar modelos.

No implementes un `delete` para esos roles solamente porque exista un endpoint o método CRUD genérico.

La autorización debe bloquear específicamente la eliminación.

---

# 6. REGLA DE ALCANCE POR ESTUDIO

El Súper Administrador tiene alcance global.

El Administrador y el Monitor tienen alcance únicamente sobre su estudio.

Una comprobación de permiso NO es suficiente si además debe verificarse el estudio.

Ejemplo conceptual:

```text
permission = models.edit
+
user.study_id == model.study_id
```

Debe revisarse el código real para determinar dónde está implementada actualmente esta restricción.

No asumas una arquitectura.
